How it works

Four layers, each doing one job. The same flow runs in this demo and in the backend code.

1. Planner agentReads the request and breaks it into small tasks with an order.
2. Worker agentsLead qualifier, CRM updater and email drafter each handle one task.
3. Tool layerREST APIs to a CRM, database or sheet. Failed calls retry automatically.
4. SupervisorPauses risky actions like sending email until a human approves.
